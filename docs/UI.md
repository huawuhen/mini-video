# 界面规范（v0.1，2026-10-15）

## 1. 原则

- **移动端优先**：先按 375×812 设计和验证，再适配 PC。
- **PC 必须可用**：≥1024px 时左侧导航 + 居中内容区（最大宽度 1200px）；项目详情页改为左右两栏。
- **浅色清新**：白色卡片放在浅灰背景上，青绿色作主色，暖橙色只用于最关键的行动按钮（如「开始制作」）。
- **一屏一件事**：每个确认步骤只问一个问题；主操作固定在底部操作栏（手机）或右侧栏底部（PC）。
- 文案中文、口语化；不出现内部 ID、错误码、JSON。

## 2. 设计令牌（唯一来源：`apps/web/src/styles/tokens.css`）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--miv-primary` | `#14B8A6` | 主色（按钮、选中、进度） |
| `--miv-primary-strong` | `#0F9488` | 按下态、强调文字 |
| `--miv-primary-soft` | `#E7F8F5` | 选中背景、标签底色 |
| `--miv-accent` | `#FF8A5B` | 关键行动按钮（开始制作、去充值） |
| `--miv-bg` | `#F5F7FA` | 页面背景 |
| `--miv-surface` | `#FFFFFF` | 卡片 |
| `--miv-text` / `-2` / `-3` | `#1F2933` / `#5B6775` / `#9AA4B0` | 正文 / 次要 / 辅助 |
| `--miv-border` | `#E6EAEF` | 分割线、描边 |
| `--miv-success` / `--miv-warning` / `--miv-danger` | `#22C55E` / `#F59E0B` / `#EF4444` | 状态色 |
| `--miv-radius-sm` / `md` / `lg` | `8px` / `12px` / `16px` | 圆角 |
| `--miv-space-1..6` | `4 / 8 / 12 / 16 / 24 / 32px` | 间距 |

Vant 主题变量在 `tokens.css` 中映射到上述令牌（如 `--van-primary-color: var(--miv-primary)`）。

## 3. 断点

| 名称 | 宽度 | 布局 |
|---|---|---|
| mobile | <768px | 底部 Tabbar（首页 / 作品 / 我的）；页面单栏；底部固定操作栏 |
| tablet | 768–1023px | 同 mobile，内容区最大宽度 720px 居中 |
| desktop | ≥1024px | 左侧固定导航栏 220px；内容区最大宽度 1200px；项目详情左侧步骤导航 + 右侧内容 |

使用 `useBreakpoint()`（`src/composables/useBreakpoint.ts`）判断，不在组件里直接写 `window.innerWidth`。

## 4. 页面地图

| 路由 | 页面 | 登录 | 说明 |
|---|---|---|---|
| `/` | 首页 | 否 | 主标语 + 输入框入口 + 风格示例 + 最近作品（已登录时） |
| `/create` | 新建 | 是 | 输入方式（粘贴/上传/想法）→ 参数 → 模式 → 报价 → 开始制作 |
| `/projects` | 我的作品 | 是 | 卡片列表，显示状态和进度 |
| `/projects/:id` | 项目详情 | 是 | 顶部步骤条 + 当前阶段视图：剧本 / 资产 / 分镜 / 生成 / 成片 |
| `/wallet` | 钱包 | 是 | 余额、冻结金额、兑换码、明细 |
| `/me` | 我的 | 否 | 未登录显示登录入口；已登录显示账号、钱包、协议、退出 |
| `/login` | 登录 | – | 手机号 + 验证码 + 同意协议；登录成功后回到 `redirect` 页面 |

## 5. 组件清单（`src/components/`）

| 组件 | 说明 |
|---|---|
| `StageStepper` | 6 步进度条（手机横向滚动，PC 竖向导航） |
| `ProjectCard` | 作品卡片：封面、标题、状态标签、进度 |
| `StatusTag` | 项目/任务状态的中文标签与颜色 |
| `PriceTag` | 金额展示（分 → 元，两位小数） |
| `AssetCard` | 资产卡片：当前选中图、候选版本缩略图、重新生成/上传/选择 |
| `ShotCard` | 镜头卡片：首帧/视频、台词、时长、take 切换、重拍 |
| `StickyActionBar` | 底部固定操作栏（PC 下变成内容区底部的普通操作区） |
| `EmptyState` | 空状态 |
| `MediaPlaceholder` | 图片/视频加载中或无内容时的占位 |

## 6. 交互要点

- 所有收费操作：先显示报价弹窗（金额 + 明细 + 余额），用户确认后才提交；余额不足时直接引导去充值。
- 生成中的卡片显示骨架屏和进度文字，不允许重复点击。
- 「暂停，我要修改」在一键模式的项目详情页始终可见。
- 替换操作完成后提示「已切换到新版本，可随时切回」。
- 登录拦截：未登录点击需登录的功能时跳 `/login?redirect=…`，登录后返回，**不自动触发收费操作**。
