# 美术素材清单与规格（v1.0，2026-10-20）

> 给美工人员的交付说明。界面原则见 `docs/UI.md`（浅色清新、移动端优先、PC 可用）。
> 代码里的颜色一律来自设计令牌（`apps/web/src/styles/tokens.css`），**素材配色请从下面的色板取**，不要另起一套。

## 0. 通用规则

| 项 | 要求 |
|---|---|
| 风格 | 浅色清新、温馨、家庭感；圆润、留白多；不出现真实品牌/名人/第三方 IP；人物以中国家庭为主，避免刻板印象 |
| 色板 | 主色 `#14B8A6`，主色深 `#0F9488`，主色浅底 `#E7F8F5`，行动暖橙 `#FF8A5B`，橙浅底 `#FFF1EA`，页面底 `#F5F7FA`，卡片白 `#FFFFFF`，正文 `#1F2933`，次要字 `#5B6775`，辅助字 `#9AA4B0`，描边 `#E6EAEF`，成功 `#22C55E`，警告 `#F59E0B`，危险 `#EF4444` |
| 模式 | 只做浅色，不做深色模式 |
| 图标 | SVG；24×24 网格；线性 2px 描边；圆角端点；**单色，颜色写 `currentColor`**；选中态另出填充版 |
| 插画 | 优先 SVG（文字一律转曲线）；复杂插画给 PNG（透明底），导出 @1x/@2x/@3x |
| 照片感/示例图 | JPG（质量 85）+ WebP 各一份，sRGB |
| 体积 | 单张插画 ≤ 200KB，示例图 ≤ 150KB（压缩后），图标 ≤ 4KB |
| 命名 | 小写英文+下划线，如 `empty_projects.svg`、`style_anime@2x.jpg`；按 §1~§6 的分组放文件夹 |
| 版权 | 交付物须为原创或可商用授权；请附来源/字体授权说明（见 §7） |

## 1. 品牌（P0）

| 素材 | 规格 | 用途 |
|---|---|---|
| Logo 横版 | SVG；透明底；留白 ≥ 高度 25%；另出白色反白版 | PC 左侧导航、登录页 |
| Logo 图标版（方形） | SVG；正方形；另出白色反白版 | 手机顶栏、加载页 |
| 网站图标 | `favicon.svg`、`favicon-32.png`(32×32)、`apple-touch-icon.png`(180×180，**不透明底**) | 浏览器标签、添加到主屏幕 |
| PWA 图标 | `icon-192.png`、`icon-512.png`、`icon-512-maskable.png`(512×512，主体在中心 80% 安全区) | 主屏幕 |
| 分享封面 | 1200×630，JPG；含 Logo 与一句标语 | 链接分享预览（微信/社交） |

产品中文名暂用开发代号 Mini AI Video，Logo 需预留“名字替换”的可能（文字与图形分层提供源文件）。

## 2. 风格示例图（P0，六张，最重要）

用于创建作品第 ① 步的风格卡片（`StylePicker`）。**六张必须是同一个场景，只换风格**，方便用户对比。建议场景：妈妈和宝宝在公园草地野餐、宝宝举着风筝。

| 文件 | 风格 | 画面要点 |
|---|---|---|
| `style_realistic` | 真人写实 | 接近真实拍摄的家庭影像，自然光 |
| `style_manga_drama` | 漫剧 | 国漫/短剧漫画风，线条清晰，戏剧光影 |
| `style_cartoon_3d` | 卡通 3D | 类皮克斯 3D 动画，柔光，温馨可爱 |
| `style_anime` | 日系动漫 | 2D 赛璐璐，色彩鲜明 |
| `style_picture_book` | 绘本水彩 | 儿童绘本、水彩肌理、柔和配色 |
| `style_clay` | 黏土 / 定格 | 手工黏土质感，定格动画感 |

规格：**3:4 竖图，1080×1440**（卡片显示约 160×213，@3x 清晰）；JPG + WebP；人物脸部勿位于底部 25%（卡片底部有文字遮罩）；不出现文字、水印。
说明：PRD 原计划在技术验证后用真实模型生成这些示例图；也可由美工绘制/渲染，**以美工版本为准**，模型可作参考。

## 4. 空状态与结果页插画（P0 带 ★，其余 P1）

统一风格，**宽 480、高 360 的画布**，主体居中，SVG（或 PNG @2x，960×720）。每张配一句文案由产品定，美工只出图。

| 文件 | 场景 |
|---|---|
| ★ `empty_projects` | 还没有作品，引导“开始第一部” |
| ★ `empty_characters` | 数字资产库为空，引导“新建数字人” |
| ★ `generating_story` | 正在理解故事 / 规划片段（等待态） |
| ★ `generating_looks` | 正在生成角色形象（等待态） |
| ★ `generating_video` | 正在生成片段（等待态，时间较长，可做 3 帧或 Lottie） |
| ★ `delivered` | 作品完成，庆祝感（轻量，不要大面积彩带） |
| ★ `failed` | 制作失败（温和、不吓人） |
| `empty_wallet` | 钱包无流水 |
| `expired` | 作品已过期，视频已清理 |
| `no_network` / `error_generic` | 网络异常 / 通用错误 |
| `not_found` | 404 页面 |
| `welcome_tour` | 新手引导欢迎页 |

## 5. 功能图标（P0）

SVG，24×24（线性）+ 选中态填充版：

- 底部/侧边导航：首页、资产库、作品、钱包、我的（5 个，各 2 态）
- 业务图标：新建数字人、上传照片、风格、画质、播放、暂停、重新生成、下载、分享、试听、删除、编辑、时长/秒、余额/充值、客服/帮助、通知
- 状态：成功、警告、失败、进行中（旋转用，单图即可）
- 媒体占位：9:16、16:9、1:1 三种比例的占位图（浅灰底 `#F5F7FA` + 居中播放/图片图标），各 960 长边，PNG

充值页的支付宝、微信支付图标**请直接使用其官方开放平台提供的品牌素材**，不要重绘。

## 6. 视频上的 AI 生成标识（P0，合规）

当前开发版 `server/src/render/assets/ai-mark.png` 是占位（942×339）。请重新设计：

| 项 | 要求 |
|---|---|
| 内容 | “AI 生成内容”文字（可加小图标）；文字清晰可读，白色，底衬半透明深色圆角矩形 |
| 规格 | PNG，**透明底**，宽 480，高按文字比例（约 120–140）；叠加时由程序缩放到画面短边约 1/12 高度 |
| 位置 | 程序固定叠加在画面左下角，请保证缩得很小时仍可读 |
| 注意 | 不得过于花哨或做成难以辨认；上线前需按合规要求复核（`docs/PRD.md` §11） |

## 7. 交付方式

1. 文件夹结构：`brand/`、`styles/`、`avatars/`、`illustrations/`、`icons/`、`placeholders/`、`ai-mark/`。
2. 每个文件夹附 `README.txt`：文件清单、字体名与授权、素材来源、是否使用 AI 生成工具（用到了需注明工具与授权）。
3. 同时交付可编辑源文件（Figma / Sketch / AI / PSD 均可）。
4. 先交 **P0 整包**（内测用），P1 后续补；先出 2~3 张样稿（一张风格示例图、一张空状态插画、一组图标）给 Lead 确认风格再批量做。
5. 交付后由开发 Agent 放入 `apps/web/src/assets/` 与 `apps/web/public/`，并替换 mock 占位；美工不需要改代码。

## 8. 优先级汇总

- **P0（M2 内测前）**：品牌、六张风格示例图、头像与声音分类头像、★ 空状态/等待/完成/失败插画、功能图标、AI 标识。
- **P1（上线前）**：其余空状态与错误页插画、分享封面、PWA 图标、加载动效。
- **P2（可选）**：Lottie 动画、节日/活动 Banner、引导页扩展插画。
