## 1. 产品概述

### 1.1 愿景

面向零基础小白、宝妈和家庭记录者的极简 AI 视频生成工具。用户只需写一段想法或生活故事，选好角色和风格，系统自动完成以下流程，用户不需要会剪辑：

**故事理解 → 角色匹配 → 片段规划 → 音画一体生成 → 自动拼接成片**

### 1.2 目标用户

- **核心群体**：宝妈、家庭生活记录者、零基础短视频创作者。
- **特征**：
  - 不懂提示词、Seed、码率等术语，也不想懂；
  - 想记录孩子和家庭日常、做温馨短剧、分享到社交平台；
  - 主要用手机，主要在微信里打开。

### 1.3 核心差异化

1. **数字人角色卡资产库**：用户用自己的照片，借助图片模型生成专属角色卡，永久保存，以后每部作品都能直接调用，保证人物前后一致。
2. **长片段一次生成**：使用单次可生成约 30 秒、自带多镜头运镜的视频模型（如 wan3.0、seedance2.5），一个片段内部的连贯性由模型保证，减少拼接带来的断裂感。
3. **音画一体**：模型直接输出带环境音、音效和对白的视频，不需要再单独合成音频。
4. **多风格可选**：真人写实、漫剧、卡通等常见风格，一键切换。

### 1.4 设计原则

- **零参数**：界面不出现任何技术参数。必须让用户选的（风格、画质档位）一律用中文名、示例图和价格来表达。
- **先报价再扣费**：所有收费动作都先展示价格，用户确认后才扣。
- **永不覆盖**：角色卡、片段重新生成时一律新增一个版本，再切换为选中版本，旧版本保留。

## 3. 端到端流程

```
[① 写故事 + 选角色 + 选风格/画质]  ── 提交前展示预估价格，确认后预占余额
        │
        ▼
[② 故事理解]  pi agent 解析故事，补全细节，识别角色并匹配角色卡
        │
        ▼
◆ 确认点 A：故事确认  ── 用户看 AI 整理后的故事梗概与角色表，可修改文字或直接「就这样，开始」
        │
        ▼
[③ 角色补齐]  故事里有、但没有角色卡的角色 → 自动生成候选角色卡
        │
        ▼
◆ 确认点 B：角色确认  ── 确认本片每个角色使用的角色卡形象（可换候选、可重新生成）
        │
        ▼
[④ 片段规划]  pi agent 按剧情把故事切成 N 个片段，决定每段时长（≤模型上限，尽量 30 秒）和片段间衔接方式
        │
        ▼
[⑤ 音画渲染]  逐段调用视频模型，生成带环境音和对白的片段（可并行；需要尾帧衔接的片段按顺序生成）
        │
        ▼
[⑥ 拼接成片]  按顺序拼接，统一响度，封装 MP4，存七牛，进入作品库
```

### 3.1 确认点规则

- 只有两个确认点：**A 故事确认**、**B 角色确认**。其余步骤全自动。
- 确认页的主按钮是「确认，继续」，一次点击就能通过。用户也可以修改后再继续。
- 用户停在确认点时，项目保持「等待确认」状态，可以随时回来继续。确认之前不会产生视频生成费用。
- 【待确认】是否提供「以后都不用问我，全自动」开关（默认关闭）。
- 角色已全部有角色卡、并且用户在第 ① 步已勾选时，确认点 B 只展示角色清单，一键通过。

### 3.2 生成后的替换（保留原始需求中的「替换/查看」）

- 成片交付后，用户可以查看每个片段，对不满意的片段「重新生成」：先报价、单独扣费，生成为新版本。
- 用户可以在同一片段的多个版本之间切换，切换后重新拼接成片。重新拼接不收模型费。
- 用户可以修改某个片段的剧情描述后再重新生成。

## 4. 核心功能需求

### 4.1 模块一：数字人角色卡资产库

**目标**：让同一个人在不同作品、不同片段里尽量保持一致。不对外承诺「完全一致」。

**数据关系**
```
角色（如「宝宝」）
 ├─ 参考照片：用户上传 1~5 张
 └─ 形象（每种风格一个形象，如「真人写实形象」「卡通形象」）
      └─ 版本：每次生成一个新版本，用户选定其中一个为当前版本
           └─ 角色卡图：定妆正面图 + 多角度/三视图（具体构成在 M0 验证后确定）
```

**功能**
- **创建角色**：填昵称（妈妈、宝宝、爸爸……）、标签（可选）、上传 1~5 张清晰照片 → 选风格 → 图片模型生成候选角色卡 → 用户选定。
- **无照片创建**：允许只用文字描述（如「5 岁小女孩，短发，爱穿黄色裙子」）生成虚构角色。
- **多风格形象**：同一个角色可以有多个风格的形象。作品选择的风格还没有对应形象时，在确认点 B 自动生成该风格的候选形象（收费，先报价）。
- **管理**：重命名、更新参考照片、重新生成新版本、切换当前版本、删除角色（删除前提示「已参与 X 部作品，历史作品不受影响」）。
- **存储**：参考照片和角色卡图都存七牛对象存储，**永久保存**在用户账号下，严格按用户隔离，只有本人能访问（私有空间加签名链接）。
- **智能关联**：用户在第 ① 步可以手动勾选角色；故事里出现「宝宝在草地上奔跑」这类文字时，系统自动匹配角色库里的「宝宝」，在确认点 A 展示匹配结果，用户可以纠正。

**计费**：生成角色卡按图片模型 SKU 计价，见第 6 节。

### 4.2 模块二：故事理解与片段规划（pi agent）

后台使用 pi agent（`@earendil-works/pi-agent-core`，沿用超搭云已验证的接入方式）作为编剧和导演。

- **故事理解**：提取梗概、角色表、场景和氛围、对白。输入过短或不明确时自动补全细节和情绪，但补全结果必须在确认点 A 展示给用户。
- **片段规划**：
  - 片段指一次模型调用的产物，内部可以包含多个镜头和运镜，由模型完成；
  - 每段时长尽量取模型上限（目标 30 秒）。agent 可以根据剧情节奏决定更短的片段，但时长必须是该模型 SKU 支持的取值；
  - agent 为每段输出：剧情描述、镜头和运镜提示、出场角色及其角色卡、对白、环境音描述、时长、与上一段的衔接方式（如「接上段尾帧」或「新场景硬切」）。
- **总时长**：【待确认】由用户在第 ① 步选择总时长档位（建议 30 秒 / 60 秒 / 90 秒），agent 在档位内规划片段数量；也可以由 agent 完全自主决定，只给上限。
- **片段间连贯**：同一场景的连续片段默认用上一段尾帧作为下一段首帧参考，保证剧情接续；具体效果在 M0 验证。

### 4.3 模块三：音画一体渲染

- 每个片段调用支持原生音画同步的视频模型，参考输入包括：角色卡图、可选的首帧或尾帧、剧情和运镜提示、对白。
- 输出带环境音、音效和角色对白的片段。
- 声音前后一致性：本期不处理（用户决定）。
- 生成失败：自动重试仅限于「明确未提交成功」的情况。提交结果未知时冻结金额并标记待处理，**不自动重提**，避免重复扣费。

### 4.4 模块四：拼接与导出

- 按片段顺序拼接，做响度统一。片段之间默认硬切；衔接方式为「接上段尾帧」的片段做无缝拼接。
- 成片规格：MP4（H.264 + AAC），按作品选择的比例（默认 9:16）和画质档位输出，生成封面图。
- 成片存七牛，进入「我的作品」。
- 【待确认】是否叠加背景音乐和字幕（音画一体已有对白，建议字幕作为 P1 可选项）。

### 4.5 风格选择

第 ① 步用带示例图的风格卡片选择，首批建议如下（最终清单与示例图在 M0 后确定）：

| 风格 | 说明 |
|---|---|
| 真人写实 | 接近真实拍摄的家庭影像 |
| 漫剧 | 国漫或短剧漫画风，适合剧情类 |
| 卡通 3D | 类皮克斯 3D 动画，温馨 |
| 日系动漫 | 2D 赛璐璐 |
| 绘本水彩 | 儿童绘本质感 |
| 黏土 / 定格 | 趣味风格 |

- 风格同时决定：角色卡使用哪个风格的形象，以及视频提示词中的风格描述。
- 一部作品只用一种风格。

## 5. 前端页面

### 5.1 首页（创作主页）

- **顶部范例轮播**：展示「一句话生成的家庭大片」，可点开播放。
- **故事输入区**：醒目的大文本框，提示语如「写下一段想记录的故事，或者宝宝今天发生的一件趣事…」，支持粘贴长文、上传 txt/docx。
- **角色托盘**：横向滚动的家庭成员头像，点击即为本次作品关联该角色；末尾是「+ 添加家人」。
- **风格与画质**：风格卡片横滑；画质档位（如「标准 / 高清」，对应模型与分辨率 SKU），每档直接标出价格。【待确认】是否让用户直接选模型，还是只选画质档位、由档位映射模型。
- **主按钮**：通栏「一键生成」，按钮上方显示「预计 XX 元」，点击后弹出费用明细确认。

### 5.2 角色库页

- 网格卡片；首格为「+ 添加家人形象」，直接调起相册。
- 角色卡片显示：头像（当前风格形象）、名字、创建时间、「已参与 X 部作品」、已有的风格形象角标。
- 详情页：参考照片、各风格形象、版本历史（可切换）、重命名、删除。

### 5.3 确认页（A 故事 / B 角色）

- **A**：故事梗概、角色表（含自动匹配的角色卡），可直接编辑文字；主按钮「确认，开始制作」。
- **B**：每个角色一行，显示所用形象，可点开换候选或重新生成；主按钮「确认角色」。

### 5.4 生成等待页

- 不允许只放一个空白转圈。用具体的进度文案：
  - 「AI 正在细读您的故事…」
  - 「正在构想画面…」
  - 「正在为您生成第 2/3 段视频与自然原声…」
  - 「正在拼接成片…」
- 已完成的片段可以先播放预览。
- 后台保活提示：「您可以锁屏或稍后再来，完成后会自动保存在『我的作品』」。

### 5.5 播放与交付页

- 全屏播放器：双击暂停、拖动快进。
- 主按钮「保存到手机」；次按钮「分享」（微信环境限制【暂缓】，先提供下载和复制链接）。
- 「片段」列表：查看每段，可重新生成或切换版本（见 3.2）。

### 5.6 其他页面

- 我的作品（含进行中、待确认、已完成、失败）、钱包（余额、充值、流水）、我的、登录。

## 6. 计费

### 6.1 原则

- 先充值余额，再按作品预估扣费。金额一律用整数「分」（CNY）。
- 流程为「报价 → 预占 → 按实际成功结果结算 → 失败部分退回」，全部通过事务账本完成。

### 6.2 计价 SKU

每个接入的模型 API，在数据库中按「模型 × 分辨率 ×（其他影响成本的维度）」建立计价 SKU。

| 字段 | 说明 |
|---|---|
| `sku_code` | 如 `video.wan3.720p`、`video.seedance25.1080p`、`image.xxx.2k` |
| 模型 / 渠道 | 对应的上游模型和接入渠道 |
| 类型 | 视频 / 图片 / LLM |
| 分辨率 | 480p / 720p / 1080p…（图片为尺寸档位） |
| 计价单位 | 视频：每秒；图片：每张；LLM：每次或每千 token |
| 售价（分/单位） | 用户价，整数分 |
| 成本价（分/单位） | 内部核算用，不对用户展示 |
| 支持的时长取值 | 视频专用，如 5/10/15/30 秒，供 agent 规划片段时使用 |
| 是否含原生音频 | 有音频与无音频价格不同时，拆成两个 SKU |
| 状态 / 生效时间 / 价格版本 | 调价时新增版本，不修改旧记录 |

### 6.3 报价公式

```
作品报价 = Σ(片段时长秒 × 视频 SKU 单价)
        + 新生成的角色卡张数 × 图片 SKU 单价
        + 故事理解费用（建议计为 0，平台承担）【待确认】
```

- 提交时，报价锁定价格版本和参数。期间如果调价，需要用户重新确认，不会静默多扣。
- 片段的实际时长以 agent 规划结果为准：确认点 A 之后才能确定精确时长，因此第 ① 步展示的是按总时长档位估算的价格，进入渲染前以精确报价为准。如果精确报价高于预占金额，需要用户再次确认。
- 余额不足：项目暂停在当前阶段，充值后继续。
- 片段重新生成、角色卡重新生成：单独报价、单独扣费。

## 7. 项目状态机

```
draft（草稿）
 → understanding（故事理解中）
 → story_review（◆A 等待确认）
 → casting（角色补齐中）
 → cast_review（◆B 等待确认）
 → planning（片段规划中）
 → rendering（渲染中，片段级子状态）
 → composing（拼接中）
 → delivered（已交付）

任意进行中阶段 → paused（余额不足 / 用户暂停）→ 恢复原阶段
任意阶段 → failed（可从失败步骤续跑）/ canceled
片段子状态：queued → submitting → generating → succeeded / failed / unknown（提交结果未知，冻结金额）
```

## 8. 存储

- 对象存储统一使用**七牛 Kodo**：参考照片、角色卡图、片段视频、成片、封面。
- 上游模型返回的临时链接，必须转存到七牛后才算成功。
- 角色资产永久保存；【待确认】作品与片段视频的保存期限（永久保存，还是例如 180 天后清理未选中版本）。
- 私有资源使用签名链接访问，按用户隔离。

---

## 9. 非功能需求

1. **零门槛容错**：不暴露技术参数；输入过短时自动补全，并在确认点 A 让用户过目。
2. **异步队列与恢复**：长耗时流程走任务队列；页面刷新、关闭、切后台后，用户从「我的作品」恢复查看进度。
3. **隐私隔离**：用户之间的资产严格隔离；家庭和儿童照片只用于该用户自己的角色卡和作品生成。
4. **账本正确性**：任何失败都不会多扣费；提交结果未知时冻结金额，等待人工或对账处理。
5. 【待确认】性能目标：如 30 秒成片从提交到交付不超过 X 分钟（M0 实测后定）。

## 10. 里程碑

| 里程碑 | 目标 | 范围 |
|---|---|---|
| **M0 技术验证** | 用真实模型验证方案并测成本（**需用户授权费用上限**） | ① 照片 → 各风格角色卡效果；② wan3.0 / seedance2.5 单段 30 秒多镜头 + 角色卡参考的一致性；③ 尾帧衔接的连贯性；④ 每秒真实成本 → 定 SKU 售价；⑤ 各模型支持的时长和分辨率取值 |
| **M1 骨架** | 模拟上游跑通全流程 | 数据库、登录、钱包账本、SKU 表、角色库、项目状态机、PG 队列与 Worker、pi agent 接入（模拟）、前端主流程（mock） |
| **M2 MVP 内测** | 接真实模型，可内测 | 真实渠道、七牛转存、拼接、片段重新生成和版本切换、兑换码充值、进度推送 |
| **M3 上线准备** | 对外开放 | 支付、运营后台（SKU 价格管理、用户、订单、失败任务）、以及下方【暂缓】项中上线必需的部分 |

## 11. 暂缓事项（用户 2026-10-16 决定本期暂不考虑，保留记录）

| 事项 | 说明 |
|---|---|
| 智能质检与自动重生成 | 抽帧巡检、角色一致性检测、自动重试 |
| 片段间声音一致性 | 同一角色在不同片段中音色可能不同 |
