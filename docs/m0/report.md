## 结论（TL;DR）

1. **方案链路全部走通**：flare 形象图 → 上传七牛 → 签名链接作为 seedance-2.5 的图片/音频/尾帧参考 → 4s / 8s / 30s 视频全部成功，人物形象高度一致，30 秒多镜头严格按提示词时间线执行，尾帧衔接几乎逐帧吻合。
2. **成本**：视频 480p=0.39 元/秒、720p=0.47 元/秒（1080p=2.80 元/秒未实测）；形象图 1k/medium=0.23 元/张。90 秒 480p 作品视频成本约 35 元——**当前 PRD 占位售价（标准 0.20 元/秒）低于成本，必须调价**（见「SKU 建议」）。
3. **排队时间波动大**：白天实测 44 分钟，晚间 3~7 分钟。「制作中」预期文案按分钟~小时级设计、轮询上限 120 分钟够用但需可配置（高峰可能触线）。
4. 未验证：1080p 实拍、故事理解 LLM 单次成本（智谱接入属 M2-BE-01）、音色一致性的人耳复听（结构上已走通，见 ⑦）。

**每秒成本曲线**（视频，元/段）：480p：4s=1.56、8s=3.12、15s=5.85、30s=11.70；720p：4s=1.88、8s=3.76、15s=7.05、30s=14.10。计价严格按秒线性、无档位溢价。

**本次累计估算**：账本 `docs/m0/cost-ledger.json` 合计 2358 分（23.58 元）= 渠道接入期 206 + 六风格 138 + 视频 2014（含早期失败重试的估算 30 分），含 3 次因本机代理 fake-IP 失败的无效估算。**远低于 300 元上限与 270 元停止线**；渠道后台实际账单以对账为准（`video-query` 可续查）。七牛侧另计约 0.08 元（`server/.data/qiniu-cost-ledger.json`）。

**排队时间**：白天（2026-10-21 上午）4s 样例排队约 44 分钟；晚间（同日 17:45~18:00）5 个任务（含 30s）排队均 3~7 分钟。**结论：排队分钟~小时级波动，产品「制作中」文案与预期管理必须按此设计；120 分钟轮询上限（BE-05）合理，但建议 M2-BE-01 把上限做成配置并在 80% 时预警。**

## SKU / 档位映射建议（供 Lead 与用户决策，非最终定价）

- **当前 PRD 占位售价低于成本**：标准 0.20 元/s < 480p 成本 0.39 元/s。建议：**标准档=480p，售 0.5 元/秒**（毛利率 ~22%）；**高清档=720p，售 0.7~0.8 元/秒**。90 秒成片对应 45 元 / 63~72 元。
- 形象：0.50 元/个（现占位）对 0.23 元成本可成立；重生成（新候选）按同价。
- 报价必须以实时目录为准（`server/scripts/modelhub-smoke.js models` 免费刷新快照），SKU 表加「渠道调价即报警」的 M2 待办。
- 1080p（2.80 元/s）不建议进首批档位。
