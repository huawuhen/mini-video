# Mini AI Video 产品需求大纲（v0.1，2026-10-15）

> 状态：大纲已与用户确认方向；带「待定」标记的条目需在实施前与用户确认。

## 1. 产品定位

面向 C 端普通用户：输入或上传剧本/脚本（也支持一句话想法），一键自动制作并交付成片。过程中用户可以查看、替换、确认剧本、角色/场景资产、分镜和每个镜头。

- 平台：移动端优先（手机浏览器、微信内打开），PC 浏览器同样可用（响应式布局）。
- 视觉：浅色清新风。
- 收费：充值余额 + 按片预估扣费（整数分，人民币）。
- 代号：Mini AI Video（中文名待定）。

## 2. 目标用户与核心场景

| 用户 | 场景 |
|---|---|
| 短剧/短视频爱好者 | 把自己写的小剧本变成 30~50 秒的短片 |
| 自媒体创作者 | 快速产出剧情类内容素材，可替换不满意的镜头 |
| 小商家（后续） | 剧情广告短片 |

## 3. 核心流程

```
① 输入 → ② 剧本确认 → ③ 资产确认（锁定）→ ④ 分镜确认 → ⑤ 逐镜生成 → ⑥ 成片交付
```

- **两种模式**：
  - 一键模式（默认）：所有确认点自动通过，用户只看进度和最终成片；随时可以点「暂停，我要修改」。
  - 精修模式：每个确认点停下，等用户确认后才继续。
- **资产锁定原则**：先确认角色和场景，分镜定稿时自动引用已锁定的资产，保证人物在各镜头里一致。

### 各步骤说明

| 步骤 | 用户看到 | 用户可以 | 是否收费 |
|---|---|---|---|
| ① 输入 | 粘贴文本 / 上传 txt、docx / 一句话想法；比例（默认 9:16）、时长（30~50 秒，待定是否扩展）、风格卡片、模式 | 提交前看到**预估价格** | 提交时预占 |
| ② 剧本 | 标题、梗概、场景卡片、台词 | 编辑文字、重新生成 | 重新生成免费（每片限 N 次，待定） |
| ③ 资产 | 角色定妆图、场景图，每项多个候选版本 | 选候选、重新生成、上传自己的图（需确认有使用权）、锁定 | 重新生成单独计费 |
| ④ 分镜 | 每镜一张卡：首帧构思、台词、时长、引用的资产 | 改台词、改时长、删/加镜 | 免费 |
| ⑤ 生成 | 每镜实时状态，完成即可播放 | 单镜重拍、上传视频替换、在多个 take 之间切换 | 重拍单独计费 |
| ⑥ 交付 | 成片播放、封面 | 下载、分享（M3）、换 BGM/字幕后重新合成 | 重新合成不收模型费 |

## 4. 功能范围与里程碑

| 里程碑 | 目标 | 范围 |
|---|---|---|
| **M0 技术验证** | 定一致性方案与成本模型 | 3 个样例剧本：纯文生视频 / 定妆图+图生视频 / 多参考图视频 / 三视图角色卡，对比一致性、单片成本、耗时（**需用户授权真实费用**） |
| **M1 引擎与骨架** | 新仓库跑通一键模式（模拟上游） | 引擎迁移、PG 队列与 Worker、项目状态机、手机号登录（短信可模拟）、钱包账本、前端主流程（mock） |
| **M2 MVP** | 完整精修流程可内测 | 6 步流程、候选与替换、字幕合成、兑换码充值、真实渠道接入、SSE 进度 |
| **M3 上线准备** | 对外开放 | 微信/支付宝支付与对账、内容安全审核、AI 标识水印、分享页、运营后台（用户/订单/失败任务） |
| **M4 增长** | 体验与渠道 | 小程序评估、风格模板库、BGM 库、作品广场 |

## 5. 项目状态机

```
draft → planning → plan_review → assets_generating → asset_review
      → storyboarding → shot_review → shots_generating → composing → delivered
任意进行中阶段 → paused（用户暂停 / 余额不足） → 恢复到原阶段
任意阶段 → failed（可续跑） / canceled
```

- `*_review` 是确认点：一键模式自动通过，精修模式等待用户。
- 上游提交结果未知时进入 failed，原因为「提交结果未知」，金额保持冻结，不自动重提，提示联系客服。

## 6. 计费规则

- 报价 = 资产生成费 + Σ(镜头时长 × 模型单价) + 合成费（可为 0）；提交时按报价预占。
- 实际按成功结果结算；失败的镜头退回；重拍、重新生成资产单独报价、单独预占。
- 报价绑定用户、参数、价格版本，有效期内有效；价格变化时需要重新确认，不静默多扣。
- 余额不足时项目进入 `paused`，充值后可继续。
- 参考成本：wan-3.0 720p 约 0.30 元/秒，40 秒短片仅视频约 12 元成本；定价待用户确认（M0 后给出建议）。

## 7. 账号

- 手机号 + 短信验证码登录（M1 可用模拟短信）；微信登录 M3 评估。
- 账号与超搭云完全独立：独立数据库、独立部署、独立域名。

## 8. 合规（上线前必须完成）

- 生成式 AI 服务备案或登记（备案主体待用户确认）。
- 输入剧本与生成结果的内容安全审核（第三方内容安全服务）。
- 《人工智能生成合成内容标识办法》：成片加显式水印（「AI 生成」）和隐式元数据。
- 手机号实名，用户协议与隐私政策，未成年人保护提示。
- 确认上游模型服务条款允许二次销售。

## 9. 非目标（本期不做）

- 无限画布、团队协作、多人实时编辑。
- 用户自选 100 多种模型（只提供少量精选组合）。
- 小程序（M4 评估）。
